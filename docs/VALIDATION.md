# 验证记录

验证日期：2026-11-06（Asia/Shanghai）。参考版本 6.2.43 / 9cff6bf。

## 已在当前 Windows 主机验证

- `npm run check`：TypeScript 类型检查通过。
- `npm test`：16 个测试组通过；1 个原生 POSIX 测试组因当前主机为 Windows 跳过。
- 原版对照覆盖全部内置预设、全部视频编码器、全部音频私有 ID、画面效果枚举及代表性的质量、流映射、字幕样式、元数据、章节、附件、复杂滤镜、剪辑、两遍编码、自定义参数和 TimeSpan 边界。
- 对照实际参数数组、滤镜图及阶段数量，不用展示字符串差异代替语义比较。
- 对照测试覆盖大小写不敏感的枚举名称、数字字符串、目录占位符引用和文件名中的字面 `$`。另验证了子目录规范化、长序号和脚本执行时的重名递增。
- 原生参数探针与 Windows FFmpeg 一样使用 CommandLineToArgvW。PowerShell 7、Windows PowerShell 5.1、CMD 交互式、下载 `.cmd` 以及完整 Windows 辅助脚本均通过空字符串、中文、引号、尾反斜杠、UNC 和特殊字符检查。
- Windows 上的 MSYS Bash 和 Zsh 验证了相对输出、暂存提交、授权覆盖及硬链接拒绝。MSYS 原生进程桥会改变部分参数路径，该项不作为 POSIX 原生验收。
- Git Bash 预检基准分别跑三次。100、500、1,000 项无冲突的中位数为 0.25、1.33、3.69 秒。预先占用每项同名候选时为 0.42、2.01、4.93 秒。计时包含 Shell 启动，不含转码。
- 合成短媒体验证了三种 Windows 脚本、缩放、AAC、两遍编码、特殊字符元数据、重名递增、修改时间保留。
- 实际验证外部字幕烧录、字幕混流、FFmetadata 章节和 MKV 附件；生成帧服务器文件的 UTF-8 内容检查通过。
- 验证了生成模板不会覆盖同名批内输入，编码失败保留旧成品，提交前拒绝被替换为源文件硬链接的目标。两个并发两遍任务分别使用自己的日志，同名成品只有一次提交成功。
- CMD 长任务包在含中文、空格和百分号的目录运行，保留调用目录及退出状态。用真实媒体核对了可选映射全部落空时的流选择。
- Edge 和 Playwright Chromium 的 `file:` 页面通过参数编辑、预设往返、ZIP 任务包、复制降级、搜索、暗/亮主题和工作区恢复。390px 与 1,024px 下的更多菜单可使用键盘进入工作区。
