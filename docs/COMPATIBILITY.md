# 兼容行为与边界

预设兼容性以 **FFmpegFreeUI（3FUI）6.2.43**（提交 `9cff6bf`）为基线，由 `upstream.json` 固定。原生预设采用 v6 JSON 格式，对应字段 `预设文件版本 = 6`。字段名和类型取自原始模型；默认值、编码器数据及内置预设由 VB 参考工具导出。构建过程只使用仓库内的这些资产。

## 往返与执行语义

原始 JSON 保留未修改的字段与嵌套扩展。命令构建使用另一个规范化对象，补齐构造器默认值并同步滤镜。原生导出不带终端、主题、媒体缓存和模板内容；这些信息由工作区文件保存。

滤镜数组原有顺序及标识保留，视频在音频之前稳定分组。新增内置项依原版默认优先级插入；旧自定义视频/音频字段迁入排序系统并在运行对象中清空。编辑排序时会合并原始项的未知字段。

自定义参数属于 FFmpeg 参数字符串，不是 Shell 脚本。先按 Windows `CommandLineToArgvW` 规则拆分，再向目标终端逐项引用。输入路径、输出路径及原版通配符按原有替换顺序处理。

## 有意差异

| 项目 | 本项目行为 |
| --- | --- |
| 未知版本、枚举、非空未知字段 | 可保留导出，但不生成“可执行”脚本 |
| 文件存在性探测 | 用户确认或提供清单；网页不声称已扫描未授权目录 |
| 模板文件 | 用户导入内容，脚本展开 `<FilePath>` 并写入实际路径 |
| 机器名称 | 保留原字段；不假装能取得终端主机名称或自动应用旧机器路径 |
| 不支持的附件容器、未知封面输出编号 | 明确阻断，避免沿用原版的静默省略 |
| 自定义视频编码器 | 合法名称明确生成 `-c:v`；修正上游自定义条目的命令名为空造成的遗漏 |
| 无法解析的 Trim/剔除中间冒号时间 | 阻断，避免原版省略该时间点而改变剪辑范围 |
| 空输出设备 | Windows 使用 `NUL`，Linux/macOS 使用 `/dev/null` |
| 无目录的 passlog 路径 | 使用当前工作目录下的相对路径；实际位置与绝对路径等价 |
| `输出目录` 字段 | 作为工作区输出目录与 `输出位置` 之后的回退目录 |
| 随机命名 | 每个工作区和任务生成稳定的随机样式后缀；刷新预览不会不断改名，新建工作区生成新种子 |
| 输出覆盖 | Forge 生成的固定输出默认使用 `-n`。完整脚本预检整批输出，临时授权只允许覆盖已确认与批内输入无关的普通文件。递增命名继续避让已有文件 |
| 执行失败 | 后续阶段停止，保留已有媒体输出；后处理失败明确返回错误 |

## 原版时间语义

原版先调用 `.NET TimeSpan.TryParse`，再调用 `Double.TryParse`。本项目保留其不直观的行为：裸整数 `10` 在需要程序计算的时间字段中表示 10 天，`10.0` 才表示 10 秒；`25:00:00` 还可能被解释成“25 天 0 小时 0 分钟”。建议填写 `00:00:10` 或 `10.0`。

“掐头去尾”沿用原版当前实现：出点实际按结束时间计算 `-t`，并未用媒体总时长减去尾部长度。仍按原版阶段规则要求导入媒体信息，不根据字段名称自行改变结果。

## 平台能力

命令生成跨平台不等于某个预设在所有硬件上都可执行。编码器、着色器、AviSynth/VapourSynth 和 libass/libplacebo 等依赖由用户的本机环境提供。程序不会自动替换编码器、安装依赖或执行生成结果。

Linux/macOS 不自动设置创建时间，也不依赖可选的 SetFile 等工具。Bash/Zsh 输出使用共同的基础引用规则与可移植文件操作。CMD 的交互式命令和批处理百分号规则分别生成，完整辅助流程使用系统 PowerShell，超长结果要求切换终端。
